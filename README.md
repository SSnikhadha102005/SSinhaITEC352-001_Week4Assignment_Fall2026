# SSinhaITEC352-001_Week4Assignment_Fall2026
Program Overview  
This project demonstrates object‑oriented programming in Python using a custom class named Sketch, chosen because it begins with the first letter of my last name (Sinha). The program includes a UML class diagram, a Python module containing the class definition, and a main script that creates objects and displays their behavior.

Class Description  
The Sketch class models a simple art sketch with three attributes:

title – the name of the sketch

medium – the material used (pencil, watercolor, acrylic, etc.)

duration_minutes – time spent creating the sketch

The class includes two methods:

describeSketch() – returns a formatted description of the sketch

estimateDifficulty() – returns an estimated difficulty level based on duration

Files Included

objects.py – contains the Sketch class

main.py – creates Sketch objects and demonstrates their methods

UML Diagram – image/PDF showing the class structure

README – explains the program

How to Run

Place objects.py and main.py in the same folder.

Run the program using: python main.py
